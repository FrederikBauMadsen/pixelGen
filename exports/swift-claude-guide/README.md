# Claude Code guide for a Swift beginner

## Setup

1. Copy `CLAUDE.md` into the root folder of the Xcode project (next to the `.xcodeproj` file).
2. Open Claude Code in that folder. It reads `CLAUDE.md` at the start of every session.
3. Edit the file as you learn. Add a line whenever Claude does something you don't want again.

## What it's based on

- The "Truth first" section comes from Frederik's own rule for Claude: don't make stuff up.
- The "How to talk to me" section is a short version of the plain-English writing rules Frederik
  uses at work.
- The Swift, build and git sections are standard practice, not taken from Frederik's chats.
  Claude had no access to those.
